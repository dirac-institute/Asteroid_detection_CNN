# BLIND EVALUATION CONTRACT — frozen 2026-06-10, BEFORE the blind test

This document pre-registers the blinded injection-on-real NEO evaluation. Nothing below may be changed in
response to blind-test results; the blind test REPORTS performance at the frozen operating points, it does
not tune them. (Validation-set selection, base-rate correction, and blind performance are three separate
things — this contract is the boundary between the first and the third.)

## 2. Frozen product configurations
- **A — 2v same-night ALERT** (`op_2v_alert.json`): S ≥ 0.80, mfsnr ≥ 5, pair_chi2 ≤ 5 (GATE only),
  rate ∈ [1,8]°/day, priorityScore = tier base + 0.95·weakest-member score, global top-50/night,
  promote_3v on. Claim tier: follow-up alert, never discovery.
  Selection rationale: S=0.80 is a conservative point on a broad J(S) plateau (0.60–0.825 ± 4%);
  mfsnr=5 is the lowest photometric cut preserving night-budget margin (13.9 FP outranking typical truth
  per 30-field night = 28% of budget). Capacity-aware alternatives documented, not adopted:
  mfsnr≥3 per-field-budget mode (+10% J at top-20/field); mfsnr≥10 rejected (deletes faint-fast yield).
- **C — 3v same-night CONFIRM** (`op_3v_confirm.json`): S ≥ 0.70, mfsnr off, 3-epoch geometric gates,
  3v-first wide-arc seeding (180 min). Claim tier: high-confidence confirmation candidate.
- **D — multi-night DISCOVERY** (`op_multinight_discovery.json`): hybrid length-split router
  (len<12 px → make_tracklets; len≥6 px → trail-as-tracklet; 6–12 px overlap band; linkage-level union),
  default S ≥ 0.80; reservoir S ≥ 0.60 permitted ONLY behind the hybrid router. minobsnights=3.
- **Control (appendix only, NOT a product):** the rejected 2v low-threshold reservoir (S≥0.60 modes) —
  reported as a control to document the +8% completeness ceiling and ranking non-recovery.

## 3. Blind data definition
- Injection population: Granvik(2018)-sampled NEOs via Sorcha; faint-fast emphasis (detection-SNR 2–10,
  rate 1–8°/day, trails ≥ 6 px), magnitudes spanning to the SNR≈2 limit; realistic same-night WFD cadence;
  injected into REAL Rubin DP2 difference images (training story unchanged: simulated trails injected
  into real images; real catalogs only for validation/regression).
- Field/night selection RULE: blind fields must be DISJOINT from the 82 validation fields (different
  tracts; different nights where possible; mix of ecliptic and off-ecliptic), and disjoint from all
  detector training/calibration visits. The selection list is generated by rule before any detection runs
  and recorded with the run.
- 2v denominator: injected faint-fast NEOs present in ≥2 same-night visits. 3v/multi-night denominators:
  present in ≥3 same-night visits / ≥3 nights respectively.

## 4. Metrics (reported per product, never collapsed into one number)
- A (2v alert): faint-fast alert completeness; alerts/night; truth-rank distribution; top-5/10/50
  recovery; search-radius distribution at +30/+60/+90 min; base-rate-scaled real-sky purity
  (C·ρ/(C·ρ+λ), ρ = 0.36 faint-fast movers/field-night, Granvik×Sorcha); latency after second visit;
  known-object/NY2-style regression where applicable.
- C (3v confirm): object completeness; track purity; false tracks/night; incremental gain over A.
- D (multi-night): object completeness; track purity; false tracks/night; runtime/tractability at 0.80
  and 0.60 floors; incremental gain over A and C.
- Baselines (the lower-stack-threshold criticism confronted directly): Rubin/Stack 5σ, Stack at a relaxed
  threshold (4σ if obtainable), vs ADCNN A / A+C / A+C+D.

## 5. Failure criteria + post-hoc diagnosis order
The blind test "fails" a product if its completeness or purity falls below half the validation-set value
at the frozen op. If that happens, thresholds are NOT retuned first; diagnose in this order:
1. detector per-sighting recall (the recall² funnel) on the blind fields,
2. score calibration / ranking transfer (score distributions blind vs validation),
3. mfsnr calibration transfer,
4. field/cadence/domain shift (seeing, depth, FP density),
5. only then threshold movement — which would require a NEW validation cycle and a NEW blind set.

## 6. Presentation commitments (paper)
- The red curves in the threshold figures are labeled "validation injected-truth fraction" — they are NOT
  real-sky purity. The paper states: "Because the injected validation set is intentionally enriched
  relative to the real NEO sky density, we also compute a base-rate-scaled real-sky alert purity; at the
  adopted 2v alert operating point this is ≈0.64%, confirming that 2v outputs are follow-up alerts, not
  discoveries."
- mfsnr is presented as capacity-aware: "The adopted mfsnr threshold depends on the operational alert
  budget. For the default top-50/night stream, mfsnr ≥ 5 maximizes usable alert yield while preserving
  margin against false candidates outranking typical truth. A lower mfsnr threshold is a valid
  high-capacity mode but is not adopted for the default stream."
- The operating point is described as the "adopted default alert operating point", not an "optimal
  threshold"; figures carry field-bootstrap 16–84% bands and the "full pair enumeration" provenance.
